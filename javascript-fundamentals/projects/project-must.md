# 🚀 The 20-Project JavaScript Mastery Roadmap (2026 Edition)

This curriculum bridges the gap from absolute beginner to production-ready developer through hands-on practice.

## 🟢 Level 1: Foundations 
*Focus: DOM Manipulation, Event Listeners, and basic logic.*

1.  **Digital Clock:** Build a live clock with date and time formatting.
2.  **Color Flipper:** A simple button that changes the background color using random HEX codes.
3.  **Counter App:** Create increment, decrement, and reset functionality.
4.  **Review Carousel:** Display user reviews with "Next" and "Previous" buttons using an array of objects.
5.  **Modal Window:** Create a reusable modal component that opens and closes with smooth transitions.
6.  **Rock Paper Scissors Game:** Implement classic game logic and track scores against a computer.
7.  **Grocery List (CRUD):** Build an app to add, edit, and delete items from a list using template literals.

## 🟡 Level 2: Interactivity & State
*Focus: Higher-order functions (map, filter, reduce) and asynchronous data.*

8.  **Menu Filter:** A restaurant menu that filters categories (Breakfast, Lunch, etc.) dynamically.
9.  **Video Player UI:** Build custom play/pause, volume, and progress bar controls using the HTML5 Video API.
10. **Countdown Timer:** Create a target date countdown (e.g., for a product launch) that updates every second.
11. **Lorem Ipsum Generator:** Generate random paragraphs of text based on user-inputted length.
12. **Sidebar & Navbar Navigation:** Master toggle classes for responsive layouts without using frameworks.

## 🟠 Level 3: External APIs & Data Persistence
*Focus: Fetch API, async/await, and LocalStorage.*

13. **Weather App:** Pull live data from OpenWeatherMap API and display it based on user search.
14. **GitHub Profile Finder:** Fetch and display user profile data and repositories using the GitHub API.
15. **Random Joke/Quote Generator:** Connect to an external API to fetch and display random content on click.
16. **Notes App:** A multi-note interface that saves user entries to `localStorage` for persistence.
17. **Infinite Scroll Blog:** Use the `IntersectionObserver` API to load more posts as the user scrolls.

## 🔴 Level 4: Advanced Mastery & Full-Stack
*Focus: Logic complexity, real-time data, and high performance.*

18. **Password Generator:** Build a secure tool with toggles for symbols, numbers, and case sensitivity.
19. **Real-Time Currency Converter:** Use a currency API to perform live exchange rate calculations.
20. **AI Chatbot Interface:** Design a chat UI that integrates with an AI API (like OpenAI) to handle streaming responses.

---
### 💡 How to Master These Projects
*   **Build without copying:** Try to build the logic yourself before looking at tutorials.
*   **Refactor:** Once it works, rewrite it to be cleaner using modern ES6+ syntax (Arrow functions, Destructuring).
*   **Responsive Design:** Ensure every project looks great on mobile using CSS Flexbox and Grid.
